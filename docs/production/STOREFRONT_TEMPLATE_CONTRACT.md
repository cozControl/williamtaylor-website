# Storefront Template Contract

The supplied William Taylor storefront is the immutable design and product source of truth. CMS schemas follow its actual visible sections; governed backend content feeds the existing compositions rather than creating alternate public designs.

## Permanent rules

1. The existing storefront composition, global chrome, responsive behavior, typography, spacing and imagery treatment remain code-owned.
2. CMS schemas map to visible template regions and make only their content, ordering, relationships and Media data-owned where authorized.
3. Product, Collection and Campaign are distinct domains and must never be represented as generic Pages.
4. Homepage uses a fixed typed composition matching its real twelve-section template. It is not a generic page builder.
5. Ordinary staff may edit content, ordering, relationships and Media exposed by a governed editor; they cannot arbitrarily redesign layouts.
6. Preview and live publication use the same frontend presenter and template. Only their revision source differs.
7. Responsive storefront behavior must be preserved.
8. Protected imported assets and existing public templates must not be changed without explicit authorization.

## Future Homepage contract

CMS-PROD-2 must retain: video hero; trust strip; new arrivals; Collection cards; Pre-Order/Limited Edition panels; dark editorial Product grid; occasion cards; full-width editorial feature; testimonials; featured Product campaign; social gallery; and journal cards. Announcement, header/navigation, newsletter, footer, contact, social links and WhatsApp remain shared global Site Content.

## Future catalogue contract

Later Catalogue phases must drive the existing Shop cards, Product detail composition, gallery, colour and size selectors, descriptions, materials/fit/care/features, badges, related Products, Collection cards and campaign panels from governed domain data. They must not introduce substitute templates.
