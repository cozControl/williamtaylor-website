# DEMO-1A known limitations

The imported public storefront JavaScript still requests a legacy Base44 public-settings endpoint that is not served locally. The focused browser evidence records the resulting public 404 and console message. This does not affect the protected Admin workflow, local framework assets, Site Content projection, or any required DEMO-1A browser assertion.

The demo does not include:

- Dynamic Product, Collection, or Campaign storefront publication
- Pricing
- Inventory
- Reservations
- Wishlist persistence
- Cart
- Checkout
- Payments
- Orders
- Customer order tracking
- Receipts
- Production launch authorization

The ready-Media selector intentionally supports existing Site Content image usages only; it does not create upload-provider behavior or alter provider binaries/default metadata.

BE-6A.1 production closeout remains deferred. BE-6A.2 has not started. No complete audit has been authorized or run for this checkpoint.
