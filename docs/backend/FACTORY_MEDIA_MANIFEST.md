# Factory Media Manifest

`database/factory/william-taylor-v1/media.php` inventories 41 local storefront images and two exact licensed Base44 MP4 URLs. Local sources have pinned SHA-256 values. Every entry has a logical key, type, MIME, title, alt/decorative treatment, rights statement, current usage, future-domain reservation, deterministic provider suffix, requirement state, and factory version.

Remote videos are HTTPS-only, host-allowlisted, size/duration bounded, and deferred from default synchronization until explicit `--include-remote`. They have no fabricated checksum. Media import does not create catalogue, product, pricing, or inventory records.
