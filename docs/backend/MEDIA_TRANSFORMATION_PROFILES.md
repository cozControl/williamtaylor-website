# Media Transformation Profiles

Code-owned profiles are `admin_thumbnail`, `admin_preview`, `product_card`, `product_gallery`, `hero_desktop`, `hero_mobile`, `editorial_content`, `social_open_graph` and `video_poster`. They define bounded dimensions, crop, quality and format. Editors cannot enter transformations. Focal coordinates are normalized from zero to one and affect delivery URLs only.

Private delivery uses short-lived signed URLs. Public integration is deferred.
