# Media Accessibility and SEO

Assets own a default alt value and classification: informative, decorative, complex or text image. Informative readiness requires meaningful default alt text. Decorative rendering uses empty alt. Future usages may override alt or decorative state contextually.

Readiness warns about caption, credit, rights source, unused state and crop metadata. This is media readiness, not SEO-profile execution or a claim of complete WCAG compliance.

## Workflow accessibility closeout

Queue items have labelled progress, textual states, per-file errors, explicit cancel/retry labels, and polite completion/failure announcements. Duplicate and replacement decisions use headings, associated reason fields, non-colour comparisons, confirmation semantics, and stale-state focus. Evidence confirms no horizontal overflow at the required viewports; no complete WCAG conformance claim is made.
