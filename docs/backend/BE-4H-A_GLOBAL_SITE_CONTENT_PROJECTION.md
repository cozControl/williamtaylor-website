# BE-4H-A Global Site Content Projection

BE-4H-A projects only designated-published global Site Content into the existing public chrome. The original BE-4H Page pilot remains blocked because none of the existing public routes is an eligible informational CMS Page. Splitting the work proves the public read boundary without adding a Page route.

Scope is limited to primary/mobile navigation, announcements, footer navigation, site profile, logos, contact, WhatsApp, social and newsletter copy. Every page body remains static. No CMS Page, catalogue, SEO, commerce, localization, API, customer-image or AI projection exists.

The feature is disabled by default. Deployment prerequisites remain release-equivalent MySQL validation, the isolated Cloudinary staging smoke test, continuous scheduler/queue supervision and a production-appropriate cache.
