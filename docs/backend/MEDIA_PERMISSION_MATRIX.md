# Media Permission Matrix

| Permission | Capability |
|---|---|
| `media.view` | Library and detail inspection |
| `media.upload` | Signed intent and verified confirmation |
| `media.edit` | Editorial, accessibility, focal and usage metadata |
| `media.replace` | Verified same-type replacement |
| `media.archive` | Reversible archive with reason |
| `media.restore` | Provider-verified restore |

CMS Manager receives all six. Super Administrator receives them through the monitored registered-permission bypass. No Media Manager role or delete permission exists.
