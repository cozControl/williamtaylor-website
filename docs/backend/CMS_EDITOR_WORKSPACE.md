# CMS Editor Workspace

The responsive Livewire editor has an ordered outline, field canvas, and context rail. Desktop presents all regions; tablet and mobile stack safely. Save Draft is primary and Preview Saved Revision remains nearby. There is no Publish, Review, Approve, or Schedule control.

The outline supports add, selection, keyboard move up/down, duplication, and removal. These controls preserve stable identity rules and provide an `aria-live` ordering announcement. The canvas provides typed fields, restricted Tiptap, ready-media selectors, and alt guidance. The context rail shows draft metadata, current revision, English locale, template, slug behavior, and change summary.

Status/conflict messages use live regions. Labels, toolbar names, visible focus, minimum control sizing, reduced motion, wrapping, and stacked responsive layouts are implemented. Unsaved navigation prompts are enabled. Validation and stale conflicts preserve component data. This is not a claim of complete WCAG conformance.

Revision history is read-only. Archived detail removes the Edit control and exposes only authorized Restore.
