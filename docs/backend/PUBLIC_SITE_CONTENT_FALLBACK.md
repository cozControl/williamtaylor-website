# Public Site Content Fallback

Fallback is surface-isolated. Invalid or absent primary navigation uses static navigation; invalid footer navigation uses the static footer groups; invalid site profile uses static brand/contact/social content; invalid or colliding announcements use the current static announcement state.

The fallback is also used when the flag is disabled, the resource is archived, no designated revision exists, ownership/schema/link validation fails, required Media is unavailable, or projection fails unexpectedly. Draft and candidate data are never fallback sources.
