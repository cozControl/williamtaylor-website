# BE-4D Media and Cloudinary Foundation

Laravel owns logical assets, immutable version facts, editorial/accessibility metadata, lifecycle and usage references. Cloudinary owns originals and derived delivery. Signed browser intents expire after five minutes; confirmation trusts only provider-verified facts. Tests use a deterministic fake and make no external requests.

Production requires a separate Cloudinary product environment. Lower environments use isolated non-production credentials and prefixes. Missing configuration fails closed. Current public assets remain untouched.

## BE-4D.1 operational closeout

The approved provider boundary now includes the direct browser upload queue, safe confirmation recovery, duplicate decisions, and fingerprinted replacement workflow. See BE-4D-1_UPLOAD_AND_REPLACEMENT_CLOSEOUT.md. The deterministic provider is non-production only and fails closed in production.
