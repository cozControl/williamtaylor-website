# BE-4H-0 Factory Baseline

Factory version: `william-taylor-factory-v1`.

The factory boundary is code-owned manifests plus explicit commands. Migrations remain schema-only. The baseline creates three configured identities, registry-owned roles, four governed Site Content resources, and a 43-entry Media inventory. Public projection remains disabled by default and protected storefront assets remain the rendering fallback.

Factory ownership is identified by stable logical keys, manifest version, revision change summaries, Media tags, deterministic provider paths, and append-only audit summaries. No mutable factory boolean is used.
