## Cross-phase rules

Each phase updates architecture decisions, permission matrix, data dictionary, threat model, operational runbook and tests proportionate to risk. Database migrations require rollback/backup strategy. Public rendering changes retain fidelity evidence. External adapters use contracts/fakes and idempotency. No phase begins until the previous checkpoint and its explicitly required business decisions are approved.
